📚 Study Overview

This interactive study tool covers the core concepts of the Pygame Squares Simulation system. The project demonstrates fundamental game development principles including physics-based movement, AI behaviors (fleeing and chasing), delta-time integration, and event-driven game loops.

Key Technical Themes:

Physics & Movement
Collision Response
AI Behaviors
Distance Calculations
Delta Time Integration
Life/Spawn Mechanics
Type Hints & Design
Game Loop Architecture
